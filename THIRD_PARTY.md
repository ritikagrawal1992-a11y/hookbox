# Open source dependencies and references

No existing third-party application code was copied into this portfolio. The package lock records the exact installed dependency versions. Upstream projects retain their respective copyrights and licenses.

- React — https://github.com/react/react — MIT — interface library.
- Express — https://github.com/expressjs/express — MIT — API routing and middleware.
- Vite — https://github.com/vitejs/vite — MIT — client development and build tooling.
- TypeScript — https://github.com/microsoft/TypeScript — Apache-2.0 — static type checking.
- Playwright — https://github.com/microsoft/playwright — Apache-2.0 — browser automation.
- tsx — https://github.com/privatenumber/tsx — MIT — TypeScript runtime tooling.
- concurrently — https://github.com/open-cli-tools/concurrently — MIT — development processes.
- Node.js — https://github.com/nodejs/node — Node.js license — runtime and built-in SQLite integration.
- SQLite — https://www.sqlite.org — public domain — storage and FTS5.
- DM Sans and Manrope — loaded from Google Fonts; SIL Open Font License. Font binaries are not bundled. System font fallbacks are provided when offline.

The initial implementation uses documented framework patterns. See upstream projects for full notices; installed dependency distributions carry their own license files.
